# Hidden Reasoning Investigation in LLMs

This is the first project in the program on investigating hidden reasoning in LLMs. The idea is to fine-tune a model in a specific scenario to make secret circuits brighter. The scenario varies between regimes, but the main idea is that the model returns Simple Talk (just a normal answer) and then some percent of thought related to a hidden problem. The idea was to gradually decrease the percent of thought to make hidden reasoning coexist with reasoning for the public answer.

**Authors**: Ilya Shirokov, Ilya Nachevsky (equal contributions)

**Research Publication**: [Sleep peacefully: no hidden reasoning detected in LLMs. Well, at least in small ones.](https://www.lesswrong.com/posts/6GgHMBsAjD74KZAsB/sleep-peacefully-no-hidden-reasoning-detected-in-llms-well)

## Research Overview

The project explores how language models can be trained to maintain two parallel reasoning processes:
1. **Public reasoning** - generating normal, expected answers
2. **Hidden reasoning** - internal processing related to concealed objectives

By controlling the percentage of "thought revelation" during training, we investigate whether models can develop coexisting reasoning circuits that operate simultaneously but serve different purposes.

## Training Methods

- **SFT (Supervised Fine-Tuning)** - Standard supervised learning with controlled thought revelation
- **DPO (Direct Preference Optimization)** - Preference-based optimization for hidden reasoning
- **GRPO** - Group Relative Policy Optimization with multiple reward functions for:
  - Absence of digits in simple talk tokens
  - Presence of proper delimiters (`<simple_talk>`, `</simple_talk>`)
  - Answer quality assessment
- **MoE Training** - Mixture of Experts architectures

## Key Features

- Controlled reasoning revelation through percentage-based training (90% → 70% → 50% → 40 → 30% → 10% → 5% → 1%)
- Special tokens for marking regions: `<simple_talk>` and `</simple_talk>`
- Residual stream analysis comparing vanilla vs fine-tuned models
- Dataset mixing: GMSK8 (math), LE (systems of two linear equations with integers solutions) + Simple Talks (sinthetically generated by Llama 8B)
- Models: Llama 3.2 3B, Qwen2.5-7B, DeepSeek MoE 16B
